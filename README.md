# درب ليبيا — نموذج MVP قابل للتجربة

واجهة عربية RTL قابلة للتثبيت كتطبيق ويب (PWA) على الهاتف، تتضمن:
- خريطة تفاعلية لطرابلس من OpenStreetMap.
- بحث عن الانطلاق والوجهة عبر Nominatim.
- حساب مسار/مسارات قيادة حقيقية من OSRM demo router.
- عرض المسافة والمدة التي يرجعها محرك المسارات.
- تحديد موقع الجهاز بإذن المستخدم.
- إنشاء بلاغات مرورية وحفظها محليًا في المتصفح وإظهارها على الخريطة.
- مخطط SQL أولي اختياري لـ Supabase.

## مهم قبل الاستخدام
هذه نسخة MVP وليست نظام مرور إنتاجيًا. OSRM التجريبي لا يقدم ازدحامًا حيًا؛ أوقات الرحلة لا تعكس بالضرورة المرور الحالي. البلاغات محفوظة في المتصفح الحالي فقط ولا تصل إلى مستخدمين آخرين. خدمات Nominatim وOSM tile العامة لها سياسات وحدود استخدام، فلا تعتمد عليها لخدمة تجارية عالية الاستخدام. راجع السياسات واستخدم مزودًا مناسبًا عند الإطلاق.

## التشغيل محليًا
1. فك ضغط الحزمة.
2. افتح الطرفية داخل المجلد.
3. شغّل خادمًا محليًا بدل فتح index.html مباشرة:
   - إذا كان Python مثبتًا: `python -m http.server 8080`
4. افتح `http://localhost:8080` في المتصفح.
5. اسمح بالموقع عند الحاجة. تحديد الموقع يحتاج localhost أو HTTPS.

## تثبيته على الهاتف
ارفع الملفات إلى استضافة HTTPS ثابتة، ثم افتح الرابط في Chrome/Android واختر Install app، أو في Safari على iPhone اختر Share ثم Add to Home Screen. بعض ميزات PWA تختلف بين الأنظمة.

## مزودو الخدمات في هذا النموذج
- الخريطة: OpenStreetMap standard tile service (للاختبار والاستخدام الخفيف فقط).
- البحث الجغرافي: Nominatim public endpoint (للاختبار؛ يجب احترام سياسة الاستخدام).
- المسارات: OSRM demo endpoint (للتجربة؛ لا يوجد SLA ولا بيانات مرور حي).

## طريق الإنتاج
1. اختر مزود خرائط ومسارات يثبت تغطيته في طرابلس (اختبر Google Routes/Mapbox أو استضافة محرك OSRM/Valhalla خاص بك).
2. ضع مفاتيح المزود في خادم backend/edge function؛ لا تضع مفاتيح سرية في الواجهة.
3. اربط Supabase Auth وقاعدة البيانات. لا تفتح قراءة البلاغات العامة مباشرة؛ اعرض فقط البلاغات المؤكدة وغير المنتهية من خلال RPC/view آمن.
4. أضف معدل إرسال، منع إساءة الاستخدام، تحقق المشرف، سياسة خصوصية، وحذف بيانات الموقع بعد فترة محددة.
5. لا تعرض ازدحامًا حيًا إلا من مزود يدعمه محليًا أو بيانات ميدانية موثوقة مع وقت آخر تحديث.

## لا توجد بيانات حية مزيفة
لا يحتوي النموذج على أرقام سرعة أو ازدحام مخترعة. عند فشل خدمة المسارات يظهر خطأ بدل اختلاق نتيجة. يجب التحقق ميدانيًا من المسارات والأوقات قبل الاعتماد عليها.
